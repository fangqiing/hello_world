# 把想法写成能画出来的 prompt

## 先按这个顺序想，后面的不许推翻前面的

1. **用途**：这张图/这段视频是干什么的？闲聊配图、表情包、头像、还是记录一件事。用途决定画法、构图、精细度。
2. **对方说过的东西一个字不改**：他点名的主体、颜色、动作、情绪、文字，全部保留。只把他没说清的地方讲明白，不许自作主张加新元素。
3. **补全**：只补他没指定的部分——光、环境、质感、风格、镜头。

## 三段式（每段都要有）

- **主体**：是什么，长什么样，什么材质/颜色/比例，正在做什么，什么表情。
- **情境**：在哪儿，前景中景背景有什么，什么时间、天气、光线，情绪通过可见的东西表达（安静=柔光+低饱和；压抑=低对比+重影）。
- **风格**：照片就写镜头焦段光圈与拍摄角度；插画就写媒介与技法；贴纸就写描边、平涂、留白。

## 照片再补五项

主体动作 / 场景细节 / 光的方向与质地 / 镜头与景深 / 表面质感（布纹、木纹、金属、皮肤）。
"午后从左侧窗进来的柔光，35mm，浅景深，能看见木纹" 比 "光线很好" 有用得多。

## 表情包（sticker）专用

Q版 chibi、大头小身、粗描边、平涂色块、纯白背景、主体居中占满、四周留白。
情绪靠表情和姿势，不靠文字。**不要任何文字、边框、水印、场景**。正方形。
用户要在图上加的字，必须原样引用，不许自己编。

## 视频再补三项

一个**连续动作**（不要写 montage / 多镜头切换）、镜头运动（推/拉/固定）、时长与画幅。
默认 5 秒、720P；先写清一个画面里发生什么，别塞故事线。

## 硬规矩

- 输出**一段流畅中文**，50–150 字，不列点、不写"请生成一张图"、不写"想象一下"。
- 用正面描述：想不要什么，就改成"要什么"（"别画字" → "纯净无文字背景"）。
- 不擅自往图里加文字；模型画字会糊。
- 不写模型专属参数、不写负面 prompt。
- 对方没说风格时按用途选一个合理的，不要反问；对方说了风格就照他说的。
- 这张 prompt 会进待确认票据给本人过目，所以**写清楚、别含糊**。
